# SelfChronicle Web (PWA)

Installable, offline-capable primary client for SelfChronicle.

## Scripts

```bash
npm ci
npm run dev
npm test
npm run build

```

## Role

- Local vault UI (Markdown + YAML)
- Day Close, Profile, Import, Handoff (see `docs/PLANNING_INDEX.md` and `BUILD_PLAN.md`)
- Service worker / PWA install

Package name: `selfchronicle-web`.
